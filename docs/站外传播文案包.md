## 三、分平台文案

### 掘金 / 技术社区

**标题（两个备选）**
1. `我用麦当劳官方 MCP 爬了全国 3664 家门店，发现 2 款活动全国都约不到`
2. `281 城 3664 店：把「哪里能办麦当劳生日派对」做成了一张可交互地图`

**正文**
```markdown
起因是个很具体的问题：朋友问「我在成都，能办麦当劳生日派对吗？哪家店？多少钱？这周六还有位吗？」
在官方 App 里回答这个要逐级点开、逐个城市试，而且没有任何横向对比视角。

于是我用麦当劳官方 MCP 做了全量只读采集：
- 281 个可预约城市（含经纬度与行政区划码）
- 3664 家可办门店
- 26 款体验活动（生日派对 / 主题派对 / 亲子读书会 / 品鉴会 / 体验营）
- 157 个场次抽样（79 城）

做成了一张可交互地图：<https://johnny37.github.io/mcd-experience-atlas/>

有几个只有把数据全拉通才能算出来的结论：
- **2 款活动全国零城市可约**（一年一度品虾会、金拱门板记尝新会）——官网上还挂着，
  但全国任何一家店都约不到
- **麦咖啡™奶铁品鉴会只有 2 个城市**（福州、重庆）
- 体验丰富度差距达 3 倍：中位数 18 款，最少 8 款，最多 23 款（福州/龙岩/泉州并列第一）

技术上几个有意思的点：
- 官方 `list-nutrition-foods` 返回的是 TOON 紧凑格式，而且行分隔符是字面量 `\n`（两字符），
  不是真换行。解析器在 `src/toon.py`，与麦当劳业务无关，可以直接拿走用。
- 官方接口几乎每个都返回「API 说明 Markdown + 内嵌原始 JSON」的混合体，
  必须用 `JSONDecoder.raw_decode` 从 `{"success"` 起解析，不能取「第一行像 JSON 的」。
- 价格是整数「分」，4850 = ¥48.50。
- `calculate-price` 传错 `productCode` **不报错**，静默返回 `price: 0`、HTTP 200 —— 最危险的一种坑。
- `query-nearby-stores` 单次只回 5 家、无分页、坐标被清零为 0.0。
- MCP Server 只支持协议版本 ≤ 2025-06-18，新版客户端默认协商更高版本会莫名失败。

项目开源，零第三方依赖（纯标准库），100 项测试全绿：
<https://github.com/johnny37/mcd-experience-atlas>

数据层、TOON 解析器、MCP 客户端封装都做了模块化拆分，想基于它做自己的项目，
直接看 CONTRIBUTING.md 里的「可复用模块清单」。

（顺带一提：点城市后地址栏会自动带上 ?city= 参数，可以直接分享你所在城市那一份。）
```

### 知乎

**标题**：`有哪些事是你去麦当劳才知道的？` 目录下答：
`全国 3664 家麦当劳门店，能办生日派对的城市和不能办的城市，我全查了`

**正文**
```markdown
先说结论：全国 281 个城市能办麦当劳体验活动，但**有 2 款活动一个城市都约不到**。

我用官方 MCP 把全国能办活动的门店全查了一遍（281 城 / 3664 店 / 26 款活动），
做成了一张可以点开的地图：<https://johnny37.github.io/mcd-experience-atlas/>

几个可能反直觉的发现：

1. **一年一度品虾会、金拱门板记尝新会 —— 覆盖城市数 0。**
   官网上还挂着，点进去发现全国都约不到。属于「已下架但没清干净」的残留。

2. **麦咖啡™奶铁品鉴会只有 2 个城市**（福州、重庆）。
   看到就想报名的话，先看看自己在不在名单里。

3. **体验丰富度差距 3 倍。** 按可体验活动款数算：
   中位数 18 款，最少的城市只有 8 款，最多的福州/龙岩/泉州是 23 款。
   也就是说「我们这能不能办生日派对」这个问题，**全国没有统一答案**。

4. 亲子读书会覆盖了全部 281 个城市，是最普适的一款；
   而「开心特工派对之深海探秘」只有 4 个城市（福建）。

孩子生日想办派对的，建议直接打开地图点自己那座城看：
<https://johnny37.github.io/mcd-experience-atlas/>

（每个城市都有专属链接，可以直接发给别人）
```
